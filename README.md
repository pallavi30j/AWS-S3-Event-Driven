# AWS S3 Event-Driven Automation Using Lambda

## Project Overview
Automates file upload events using Amazon S3 and AWS Lambda, with execution logs monitored through Amazon CloudWatch.

## AWS Services Used
- **Amazon S3:** Stores uploaded files.
- **AWS Lambda:** Executes Python code automatically.
- **Amazon CloudWatch:** Monitors execution logs.
- **AWS IAM:** Manages permissions.

## Workflow
1. Create an S3 bucket.
2. Create a Python Lambda function.
3. Configure an S3 upload event trigger.
4. Upload a test file.
5. Verify execution in CloudWatch Logs.

## Outcome
Successfully demonstrates event-driven serverless automation using AWS.

**Technologies:** AWS S3, Lambda, Python, CloudWatch, IAM.
